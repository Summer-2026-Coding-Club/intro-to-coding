# Extra Resources

Optional — use these if you want more practice, a different explanation, or to go further after the walkthrough.

- [Python official tutorial](https://docs.python.org/3/tutorial/) — the reference, thorough but a bit dense.
- [freeCodeCamp: Python for Beginners](https://www.youtube.com/watch?v=rfscVS0vtbw) — long-form video course, good if you like following along.
- [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/) — free book, practical projects (free online).
- [Python Tutor](https://pythontutor.com/) — visualizes your code running line by line, great for understanding what's actually happening.
- [W3Schools Python](https://www.w3schools.com/python/) — quick reference with a "try it yourself" editor for any topic.
- [Google Colab](https://colab.research.google.com/) — run notebooks in your browser, no install needed.

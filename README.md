# Introduction to Coding (and Coding in Python!)

Hi all! This is supplementary material for anyone who hasn't coded before, or hasn't coded in Python before.

## How this repo is organized

- [`00_setup.md`](00_setup.md): Learn how to install Python, and how to run a `.py` script vs. a Jupyter notebook. (This is the first step!)
- [`hello_world.py`](hello_world.py): a small Python script, used in the setup guide to practice running code from the terminal.
- [`walkthrough.ipynb`](walkthrough.ipynb): the main walkthrough. This notebook has explanations, and example cells, and then exercises you can do yourself.
- [`RESOURCES.md`](RESOURCES.md): extra outside resources if you want more practice or a different explanation of something.

## About the exercises

Exercises in `walkthrough.ipynb` are **open-ended**: try these on yourself first!

If you are stuck or want to check your work, solutions live on a separate `solutions` branch on git.
